# About Me — Personal Portfolio

A personal portfolio website built with React, Redux, and Webpack. Deployed on GitHub Pages.

## Live

[https://anhlongphan.github.io/AboutMe/](https://anhlongphan.github.io/AboutMe/)

## Tech Stack

- React 18, Redux, React Router DOM v6
- Webpack 5 + Babel
- Bootstrap 5, AOS animations, Bootstrap Icons

## Run locally

```bash
cd AboutMe
npm install
npm start
```

## Deploy

```bash
cd AboutMe
npm run deploy
```
